# ОнкоАтлас · отчёт об аудите от 21 ноября 2026 года

## Статус

Аудит частичный. Статические и браузерные тесты охватывают все 38 карточек. Клинические правки внесены в 27 карточек. Сверка охватывает выбранные показания, дозы, стадии, регуляторные изменения и элементы сопровождения. Для каждой карточки ещё требуется полный проход по WHO, морфологии, ИГХ, молекулярной диагностике, всем лечебным ситуациям, инструкциям к каждому компоненту и сопроводительной терапии. Независимая врачебная рецензия не проводилась. Сайт сохраняет статус редакционного черновика.

Исходная точка для сравнения и отката — [de7f908](https://github.com/oncoatlas-med/oncoatlas-med.github.io/commit/de7f9084542f55bdc78483ab1da4b96d2f19a4a8). [Сайт](https://oncoatlas-med.github.io/)

## Клинические изменения

Добавлены **24 самостоятельных дозовых режима или этапа лечения**. В эту цифру входят один режим с фторурацилом и митомицином и 23 записи в `regimens.json`. Режимы, показанные в нескольких применимых стадиях, считаются один раз. Клинически уточнены 10 существующих записей о режимах при раке носоглотки, плоскоклеточном раке кожи, NET тонкой кишки и поджелудочной железы, раке полового члена, анальном раке, герминогенных опухолях яичка и ГЦК.

- Для носоглотки указана версия AJCC. Прежняя IVA M0 по AJCC 8 соответствует III по AJCC 9 для T4 или N3 при M0. В AJCC 9 обе подстадии IV относятся к M1. Индукция отделена от рецидивной/метастатической терапии. Добавлены два показания торипалимаба. [ACS/AJCC](https://www.facs.org/quality-programs/cancer-programs/education/ajcc-protocol-webinar-on-version-9-staging-system-for-nasopharynx-cancer/) · [FDA, Loqtorzi](https://www.accessdata.fda.gov/drugsatfda_docs/label/2026/761240s006lbl.pdf)
- Для герминогенных опухолей яичка удалена IV стадия. Категории AJCC разграничены с прогностическими группами IGCCCG. Для адъювантной BEP указано расхождение между EAU и eviQ по числу циклов. [NCI PDQ](https://www.cancer.gov/types/testicular/hp/testicular-treatment-pdq) · [EAU](https://uroweb.org/guidelines/testicular-cancer/chapter/disease-management) · [eviQ №319](https://www.eviq.org.au/p/319)
- Из тактики при меланоме II стадии убрано назначение адъювантной BRAF/MEK-терапии. Указаны подстадии IIB/IIC для адъювантного анти-PD-1. В карточке фолликулярной лимфомы отражён отзыв одобрения таземетостата в США. Для медуллярного рака щитовидной железы отражено исключение показания пралсетиниба из инструкции FDA. [FDA, Keytruda](https://www.accessdata.fda.gov/drugsatfda_docs/label/2026/125514s192lbl.pdf) · [FDA, отозванные показания](https://www.fda.gov/drugs/cancer-approvals/withdrawn-cancer-accelerated-approvals)
- При ГЦК уточнены роль BCLC и требования к оценке вариксов перед бевацизумабом. При уротелиальном раке исключено требование определять Nectin-4 для энфортумаба с пембролизумабом, добавлена ссылка на периоперационное показание FDA. Для НЭО сохранён приоритет аналогов соматостатина у большинства подходящих пациентов с NET тонкой кишки. Для CAPTEM уточнены гистотип и опухолевая нагрузка. [eviQ №3881](https://www.eviq.org.au/p/3881) · [eviQ №4427](https://www.eviq.org.au/p/4427) · [ASCO GEP-NET](https://pubmed.ncbi.nlm.nih.gov/37774329/)
- При анальном раке добавлен радикальный режим ACT II. Капецитабин указан как пероральная альтернатива с ограниченной сравнительной доказательной базой. Для неоперабельного рецидива/метастазов добавлена первая линия с ретифанлимабом. TIP при раке полового члена привязан к массивному регионарному поражению M0. [eviQ №82](https://www.eviq.org.au/p/82) · [eviQ №1959](https://www.eviq.org.au/p/1959) · [FDA, Zynyz](https://www.accessdata.fda.gov/drugsatfda_docs/label/2026/761334s009lbl.pdf) · [EAU](https://uroweb.org/guidelines/penile-cancer/chapter/disease-management)
- Для лимфом обозначена Lugano. Первая линия распространённой болезни изложена отдельно от рецидива и рефрактерности. Добавлены N-AVD и Pola-R-CHP. Для глиобластомы, миеломы, ОМЛ и ХМЛ подтверждено отсутствие кнопок TNM I–IV. Добавлены укороченный курс ХЛТ и следующий этап темозоломида, DRd, азацитидин с венетоклаксом и асциминиб. [NCI, Lugano](https://www.cancer.gov/types/lymphoma/hp/aggressive-b-cell-lymphoma-treatment-pdq) · [eviQ №5035](https://www.eviq.org.au/p/5035) · [eviQ №4434](https://www.eviq.org.au/p/4434) · [ELN 2025](https://www.nature.com/articles/s41375-025-02664-w)

## Проверка и остающаяся работа по карточкам

«Обновлена» указывает на точечные правки в этом аудите. Все строки ниже остаются открытыми для полной клинической верификации. Технически каждая карточка доступна по прежнему идентификатору.

- **001 Аденокарцинома лёгкого.** Обновлена первая линия для EGFR exon 20. Остаются периоперационные режимы, весь спектр драйверов, показания после прогрессирования и национальные инструкции.
- **002 Плоскоклеточный рак лёгкого.** Технически проверен. Остаются клиническая сверка PD-L1 и показаний к молекулярному тестированию, периоперационные режимы и последующие линии.
- **003 Мелкоклеточный рак лёгкого.** Технически проверен. Остаются соответствие категорий ограниченной и распространённой болезни, консолидация, профилактическое облучение мозга и последующие линии.
- **004 Рак молочной железы.** Обновлена HER2+ первая линия. Остаются ранние и метастатические алгоритмы по подтипам, включая новые периоперационные показания FDA, а также секвенирование после ADC.
- **005 Колоректальная аденокарцинома.** Добавлены MSI-H/dMMR и BRAF V600E варианты. Остаются отдельные алгоритмы для прямой/ободочной кишки, RAS, HER2, KRAS G12C, резекция метастазов и последующие линии.
- **006 Рак желудка.** Добавлены режимы для HER2+/PD-L1 и HER2−/CLDN18.2+. Остаются HER2− иммунотерапия по CPS/MSI, периоперационная тактика и последующие линии.
- **007 Рак пищевода.** Технически проверен. Остаются отдельные алгоритмы для плоскоклеточного рака и аденокарциномы, резектабельность, CROSS, FLOT и постоперационный ниволумаб.
- **008 Аденокарцинома поджелудочной железы.** Добавлены NALIRIFOX и гемцитабин + nab-паклитаксел. Остаются дозовые режимы других линий, лечение погранично резектабельных опухолей и поддержка по gBRCA.
- **009 Гепатоцеллюлярная карцинома.** Добавлен STRIDE, уточнены BCLC и безопасность IMbrave150. Остаются полная тактика по BCLC, варианты иммунной первой линии и выбор после прогрессирования.
- **010 Холангиокарцинома.** Технически проверена. Остаются раздельные схемы стадирования по локализации, билиарная декомпрессия, молекулярная терапия и вторая линия.
- **011 Светлоклеточный рак почки.** Добавлен пембролизумаб + акситиниб. Остаются показания к адъювантной терапии, IMDC, альтернативные иммунные комбинации и последующие линии.
- **012 Уротелиальный рак мочевого пузыря.** Уточнены MIBC и показания EV + пембролизумаб. Остаются дозовые периоперационные режимы, NMIBC, тримодальная терапия, поддержка авелумабом и FGFR.
- **013 Рак предстательной железы.** Технически проверен. Остаются полные алгоритмы локальной терапии по риску, M0/N1, гормоночувствительного и кастрационно-резистентного заболевания.
- **014 Герминогенные опухоли яичка.** Исправлены стадии и описание адъювантной BEP. Остаются семинома, отдельные подстадии, VIP/EP, остаточные массы и спасительная терапия.
- **015 Рак эндометрия.** Уточнены категории FIGO IV. Остаются полный FIGO 2023 по молекулярным группам, послеоперационный риск, схемы иммунотерапии и линии рецидива.
- **016 Эпителиальный рак яичников.** Уточнена впервые диагностированная IV стадия. Остаются хирургические критерии, подтипы, поддержка BRCA/HRD и терапия при устойчивости к платине.
- **017 Рак шейки матки.** Технически проверен. Остаются разделение IVA и IVB, показания к брахитерапии и схемам с пембролизумабом, последующие линии.
- **018 Рак вульвы.** Технически проверен. Остаются FIGO, сторожевые узлы и распространённость пахового поражения, объём хирургии и показания к ХЛТ.
- **019 Плоскоклеточный рак головы и шеи.** Исправлен адрес PDQ. Остаются отдельные локализации и HPV-ассоциированное стадирование, радикальная помощь при M0, периоперационные показания и системные линии.
- **020 Дифференцированный рак щитовидной железы.** Технически проверен. Остаются возраст-зависимое стадирование, риск рецидива, критерии радиойод-рефрактерности и выбор системной линии.
- **021 Медуллярный рак щитовидной железы.** Уточнён статус пралсетиниба. Остаются обследование при MEN2, объём шейной лимфодиссекции, показания и сравнение системных схем.

- **023 Мягкотканная саркома.** Технически проверена. Остаются стадирование по локализации, гистотип-специфические режимы и границы применения хирургии/ЛТ.

## Техническая проверка

- 38 карточек и 139 доступных лечебных представлений. 95 представлений содержат дозовые режимы. Отсутствие режима может отражать клиническую ситуацию без системной терапии или пробел данных.
- Автоматические проверки охватывают синтаксис JavaScript, валидность JSON, уникальность идентификаторов, сверку сборки и связи между карточками и режимами.
- Браузерный тест Chromium проверяет все 38 карточек при ширине 1280 и 360 пикселей, каждую доступную стадию, оба раздела лечения, поиск, группировку, избранное, браузерную историю, неверные адреса и библиотеку знаний. PDF сформирован и проверен по извлечённому тексту.
- Поиск индексирует препараты из отображаемых режимов. Печать включает обе вкладки выбранной стадии. Новые режимы выделены в JSON. Скрипт сборки синхронизирует встроенные данные, CSS и JavaScript в статическом HTML. Общий дизайн сохранён.

## Источники

- В исходной версии проверены 127 уникальных адресов. Шесть адресов возвращали 404. Исправлены eviQ №1959 и №4154, инструкция FDA для цемиплимаба и три адреса NCI PDQ для носоглотки, ротоглотки и NET поджелудочной железы. Ссылка ДВККЛ также перенаправлена на профильный раздел NCI об агрессивных B-клеточных лимфомах.
- В обновлённой версии выполнены HTTP GET с переходом по перенаправлениям для 170 уникальных адресов. Получены 157 ответов HTTP 200, включая все 70 адресов eviQ. Ответов HTTP 404 не было. Тринадцать адресов вернули 203, 403, 406 или 503. Внешние проверки через поиск позволили прочитать часть материалов, заблокированных при прямом запросе.
- Для eviQ в журнале указаны конечный URL, заголовок HTML или PDF-адрес. Для новых режимов и части изменённых записей указаны первоисточник и дата сверки. HTTP 200 подтверждает доступность. Полная сверка показаний, доз, безопасности и соответствия всех исторических записей конечным документам не завершена.
- Полные тексты NCCN и весь массив актуальных рекомендаций Минздрава РФ не были доступны для проверки в этой сессии. Сопоставление FDA, EMA, РФ и статуса off-label по всем схемам остаётся открытым. [Журнал HTTP-проверки](audit/source-check-2026-11-21.csv)
