# ОнкоАтлас — бета-версия 0.2

Бесплатный статический русскоязычный справочник для врачей. Откройте `index.html` в браузере. Работает без сервера и без интернета (за исключением переходов к внешним источникам).

## Содержимое
- 38 кратких карточек злокачественных новообразований: гистология/локализация, молекулярные паттерны, диагностика, онкомаркеры, краткая терапия по стадиям I–IV.
- 10 кратких справочных блоков TNM/FIGO (неполные; не предназначены для автоматического стадирования).
- 8 калькуляторов: Mosteller, Calvert, Cockcroft–Gault, ИМТ, ANC, кальций с поправкой на альбумин, QTc Fridericia, ориентир RECIST 1.1.
- 4 шкалы/классификации с интерактивными формами или описанием: ECOG, Karnofsky, Khorana, Child–Pugh, IMDC (5, включая Karnofsky).
- Поиск, избранное в браузере, печать в PDF.

## Важно
Это редакционный черновик без независимой медицинской экспертизы. Упрощённые карточки не охватывают все подстадии, линии, режимы, противопоказания и различия регистрации лекарств. Не использовать для назначения лечения без сверки с действующими клиническими рекомендациями и инструкциями. Справочные ссылки на NCCN, ESMO, ASCO, NCI PDQ, UICC и клинические рекомендации Минздрава РФ приведены на сайте; они пока не привязаны к каждому конкретному утверждению.

## Публикация бесплатно
Создайте публичный репозиторий на GitHub, загрузите `index.html`, откройте Settings → Pages → Deploy from a branch → main / (root). Публикация будет доступна по адресу вида `https://USERNAME.github.io/REPO/`. Для пользователей в России/СНГ доступность конкретного сервиса нужно проверить на реальных сетях. Публикуйте только после медицинской проверки.

## Безопасность и обновления
Публичная версия доступна без регистрации. Кнопка «Икбал Р.В.» пока показывает информационную страницу, а не реальный вход. Никакие пароли в код не включены. Не публикуйте пароли и персональные данные пациентов. Для безопасного редактирования через ChatGPT в будущем потребуется отдельное подключение репозитория и подтверждение каждого изменения.

## Файлы
`index.html` — самодостаточная версия для просмотра и размещения. `cards.json` — редактируемые карточки. `app.js`, `style.css` — исходники; при изменении исходников нужно заново собрать `index.html`.
