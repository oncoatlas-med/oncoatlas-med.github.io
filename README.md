# ОнкоАтлас

Русскоязычный учебный справочник по клинической онкологии. [Опубликованная версия](https://oncoatlas-med.github.io/)

Справочник содержит 51 карточку, учебные блоки стадирования, калькуляторы, шкалы и библиотеку знаний. Поиск использует названия опухолей, гистотипы, биомаркеры и препараты. Избранное хранится в браузере. Команда «Сохранить PDF» печатает карточку с лекарственными и хирургическими сведениями для выбранной стадии или разделом клинических ситуаций.

## Редакционный статус

Проект остаётся бета-версией. Перечень клинических исправлений, результаты технических тестов и объём оставшейся проверки приведены в [отчёте от 21 ноября 2026 года](AUDIT-2026-11-21.md). Независимая медицинская рецензия не проводилась.

## Сборка и проверка

Содержимое карточек редактируется в `cards.json`, новые лекарственные режимы — в `regimens.json`. Исторические режимы, навигация и калькуляторы находятся в `app.js`. Оформление хранится в `style.css`. Библиотека знаний — отдельная страница `learning-library.html`.

```sh
node scripts/build.mjs
node scripts/check.mjs
node scripts/check.mjs --inventory
python3 scripts/check-sources.py
```

Сборка переносит данные, JavaScript и CSS в самодостаточный `index.html`. Скрипт проверки сравнивает встроенную версию с исходниками. Для локального просмотра можно открыть `index.html` без сервера. GitHub Pages обслуживает содержимое корня ветки `main`.

Для браузерного теста установите Playwright с Chromium и утилиту `pdftotext`. Переменная `ONCOATLAS_TEST_URL` переключает тест с локального файла на опубликованный сайт.

```sh
node scripts/browser-check.cjs
ONCOATLAS_TEST_URL=https://oncoatlas-med.github.io/ node scripts/browser-check.cjs
```
